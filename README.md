# Relatorio Cyber Brasil 2025

Site simples feito em HTML e CSS sobre ataques ciberneticos em cinco empresas brasileiras no ano de 2025.

## Empresas analisadas

- C&M Software
- Sinqia
- Grupo Jorge Batista
- XP Investimentos
- Monbank

## Conteudo

- Resumo geral dos incidentes
- Prejuizos divulgados ou estimados
- Principais brechas de seguranca
- Recomendacoes para reduzir riscos
- Fontes consultadas

## Como abrir

Abra o arquivo `index.html` no navegador.

## Como publicar no GitHub Pages

1. Crie um repositorio no GitHub.
2. Envie os arquivos `index.html`, `styles.css`, `README.md` e `.nojekyll`.
3. Entre em `Settings`.
4. Va em `Pages`.
5. Em `Branch`, escolha `main` e a pasta `/root`.
6. Clique em `Save`.
